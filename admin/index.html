Write letters on the official letterhead (logo, business name, GSTIN, contact details), then download as PDF, print, and save them to a register.

Where letters are saved

Letters can contain personal information, so they are never saved on the public website. Each saved letter is kept in this browser's register and downloaded as a PDF — file the PDFs in HumanAI-Documents\Letters. See ADMIN-GUIDE section 4a.

Everyone who contacts you through the website form or WhatsApp is logged here (when the free chatbot service is set up — ADMIN-GUIDE section 9). Entries delete themselves after 12 months.

Editing text

Click on any words on the page and type. Formatting shortcuts: Ctrl+B bold, Ctrl+I italic. Undo with Ctrl+Z.

Adding or removing items

Click an item (for example a service point, a FAQ question or a card). In Selected, choose the right level, then Duplicate, Move up/down or Delete.

Select a button or link; the Link box lets you change where it goes.

Photos

Saving & going live

Press Save changes → Save into my website folder and choose your VS Code repo folder (humanaihelp.github.io) the first time. The changed files are written straight into it. Then in VS Code: Source Control → type a message → Commit → Sync / Push. The live site updates about a minute later. On phones (or browsers without folder access) the changes download as a zip instead — unzip it into the repo folder. Unsaved changes are kept on this device as a draft.

Collapsible sections

In the editor, all collapsible sections and tabs are shown open so you can edit them. On the live site they stay collapsible.

Safety

This page holds no GitHub key — it can only change files on your own computer. Going live always happens through VS Code with your own GitHub sign-in.
