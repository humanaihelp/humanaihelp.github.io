# HumanAI Concierge Services — Website

Static website (HTML + CSS + vanilla JS, no build step) hosted free on GitHub Pages at
**https://humanaihelp.github.io**, with a visual admin page at **/admin/**.

👉 **Read [ADMIN-GUIDE.md](ADMIN-GUIDE.md)** — hosting, admin page, phone app and Google Play Store, step by step.

## What's inside
- 11 pages: Home, Services (10 collapsible services), How we work, About us, Plans & quotes, Contact (sends to WhatsApp), Disclaimer, Refund & cancellation, Privacy, Terms, 404
- Admin page (`/admin/`): click-to-edit every text, link and image; site-wide settings (phone, WhatsApp, email, hours, GSTIN, Google review/maps links, colours, logo); chat-assistant answers; Letter Studio (official letterhead PDFs saved to a private repo); publish to GitHub in one click
- "Ask us" chat assistant (free, runs in the browser, hands over to WhatsApp)
- Installable phone app (PWA) + ready for Google Play via PWABuilder
- Brand kit: logos, social images, visiting cards, letterhead, document/quotation/presentation templates, email signature, Play Store images

## Notes
- The repository must be public on GitHub's free plan — never upload client data, IDs or private documents here.
- Legal pages are carefully prepared starting versions; have them reviewed by a qualified professional.
